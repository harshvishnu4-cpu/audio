CommKit
Word PopRocket ReadCourse

Audio and text checking for any learning page

Add one script and your game or interactive page can listen to a learner read, hear the word they say, score a spoken or written answer and read text aloud. It all runs on the device, so it works offline.

Works offlineSpeech is checked on the device. Nothing is sent anywhere.
One line to addA script tag; the 37 MB speech model loads only when a page first listens.
Tags or codePaste a ready tag, or call the functions from your game.
Indian EnglishTuned for learners: accents aren't marked as mistakes.

1. Add the kit

Copy the kit folder into your project (see the README), then add this one line to any page.

<script src="kit/commkit.js"></script>
<!-- optional: keep it working offline after the first visit -->
<script>CommKit.offline();</script>

2. Paste a ready tag (no coding)

Each tag is a complete activity. "Try a sample" plays a recording, so you can see it work without a microphone.

<read-aloud
  heading="Read aloud"
  text="Every morning my grandmother…">
</read-aloud>

// the result, when the learner finishes
el.addEventListener('result', e => {
  e.detail.score   // 0–10
  e.detail.missed  // ['my', 'the', …]
});
<speak-answer
  prompt="What did you do last weekend?"
  min-sec="45" max-sec="60"
  points="when: saturday, sunday;
          what you did: went, visited, played;
          who you were with: with, family, friend;
          how you felt: enjoyed, happy, tired">
</speak-answer>
// points: "label: words that show it; next label: …"
<write-answer
  format="reply"  <!-- email | reply | summary | opinion -->
  min-words="40" max-words="90"
  prompt="Write a polite reply."
  points="says sorry: sorry, apologise;
          offers a fix: replace, refund">
</write-answer>

3. Use it in a game

Two small games built with the kit. Open them and read the code: each is one HTML file.

🎈Word PopSay the word on a balloon to pop it. Uses CommKit.hear(). 🚀Rocket ReadThe rocket climbs with every word you read. Uses CommKit.readAloud(). 
// hear one of a few words (fast: it only listens for these)
const said = await CommKit.hear(['apple', 'banana', 'mango'], { timeout: 6000 });
if (said.word === 'banana') score++;      // said.word is null if none was heard

// follow a reading live, then get the marks
const reading = CommKit.readAloud({ text, onProgress: (i, total) => moveRocket(i / total) });
const r = await reading.done;                // stops by itself after the last word
showStars(r.score);                             // 0–10, plus r.missed, r.changed, r.wcpm …

4. Text: listen and type

CommKit.say() reads text aloud with the device's own voice, and CommKit.compareText() checks what was typed, word by word.

Then type what you heard.

All functions

FunctionWhat it doesGives back
CommKit.readAloud({ text, onProgress })Listens to the learner read the text; follows along live; stops after the last word.done → score /10, missed, changed, added, words a minute
CommKit.hear(words, { timeout })Waits for one of a few words or phrases{ word, heard, confidence, timedOut }
CommKit.listen({ onPartial })Writes down whatever is said.done → { text, words, pauses }
CommKit.speakAnswer({ task })Scores a spoken answer: key points, time, pace, pauses, fillers.done → score /16, level, what to improve
CommKit.checkText(text, task)Scores a written answer: key points, length, common slips, structurescore /16, level, fixes, a better version
CommKit.compareText(expected, typed)Checks typing or dictation word by word{ score 0–1, words: ok / close / wrong / missing }
CommKit.say(text)Reads text aloud with the device's voiceresolves when finished
CommKit.offline()Keeps the kit and model on the device for offline usetrue when set up

Every listening function also takes audio: 'recording.wav' to check a recording instead of the microphone, which is handy for testing. Full guide: kit/README.md.
